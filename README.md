# DeepTrace — AI Deepfake Detection
Made by Phillip Rzeszótko and Michał Domański
> CNN-based image forensics system for detecting AI-generated and deepfake imagery.  
> Two interfaces: a Spring Boot web app and a standalone desktop screen-snip tool.

---

## ⬇️ Download

**[👉 Latest Release — DeepTrace v1.0](../../releases/latest)**

Download `DeepTrace.zip`, extract anywhere, run `DeepTrace.exe`. No Java, no Python required.

## How to Use

### Desktop Snip Tool
1. Run `DeepTrace.exe` — a **D** icon appears in your system tray
2. Double-click the icon to begin
3. Your screen dims — drag to draw a box around any face
4. Release — the model analyses and returns **REAL** or **FAKE** with a confidence score
5. Press **ESC** or right-click to cancel at any time

> **Windows Security Note:** On first run Windows may block the exe files.  
> Right-click → Properties → tick **Unblock** → OK  
> Or: Windows Security → Virus & Threat Protection → Exclusions → Add this folder.

## Web Architecture

The browser-based interface runs as a Spring Boot application on `localhost:8080`.
Image uploads travel over HTTP as `multipart/form-data`, are written to a temp file by the Java controller, passed to the Python inference script via subprocess, and the JSON result is returned as an HTTP response rendered live in the browser.

```
Browser  ──[HTTP POST multipart]──▶  Spring Boot (Java 17)
                                            │
                                     saves temp file
                                            │
                                   ProcessBuilder subprocess
                                            │
                                     infer_v2.py
                                     WaveletHybridNet
                                     RGB + Wavelet branches
                                            │
                                      JSON stdout
                                            │
Browser  ◀──[HTTP JSON response]────────────┘
```

## Models

### v1 — SimpleCNN (Baseline)

A lightweight two-layer CNN trained on the Stable Diffusion v1.5 subset of the dataset.
At this stage only 200GB of training data was available, so the initial training was limited to **Stable Diffusion v1.5** imagery (`imagenet_ai_0424_sdv5`). While fast, the model learned only surface-level pixel patterns and struggled to generalise beyond the generator it was trained on.

| Layer | Details |
|---|---|
| Conv1 | 3→16 channels, 3×3, ReLU, MaxPool |
| Conv2 | 16→32 channels, 3×3, ReLU, MaxPool |
| FC | 128 → num_classes |
| Input size | 224×224 |

### v2 — WaveletHybridNet (Current)

In the second iteration the training collective was expanded to include images generated by **DALL·E**, **Stable Diffusion v1.5**, and **Wukong (diffusional)**, significantly improving cross-generator generalisation.

The architecture processes each image through two parallel branches whose outputs are fused via a learned attention mechanism:

```
Input Image (128×128)
        │
        ├──────────────────────────────┐
        ▼                              ▼
  RGB Branch                   Wavelet Branch (db4, 2 levels)
  Conv(3→32) + BN + Pool        ┌─ Level 1: LL1, LH1, HL1, HH1
  Conv(32→64) + BN + Pool       └─ Level 2: LL2, LH2, HL2, HH2
  Conv(64→128) + BN                         │
        │                        Level Attention (learns which
        │                        wavelet level matters more)
        │                                   │
        └──────── Residual Fusion ───────────┘
                        │
                  RGB Refinement × 2
                  Wav Refinement × 2
                        │
               Global Average Pool
                        │
              Final Attention (RGB vs Wav)
                        │
               FC(128→64) → FC(64→2)
                        │
                  REAL / FAKE
```

The wavelet branch decomposes the image using a **Daubechies db4** wavelet at 2 levels, extracting the high-frequency subbands (LH, HL, HH) that encode the subtle compression and generation artifacts left behind by GAN and diffusion models — artifacts invisible to a standard RGB CNN.

**Training configuration:**
| Parameter | Value |
|---|---|
| Optimiser | AdamW |
| Learning rate | 1e-4 |
| Weight decay | 1e-4 |
| Batch size | 8 |
| Input size | 128×128 |
| Wavelet | db4, 2 levels |
| Validation | 2-fold cross-validation |
| Early stopping | patience = 3 |

## SVM Baseline Results

Before the CNN models, a classical SVM pipeline was evaluated across multiple handcrafted feature sets on 40,000 training images (20k real, 20k fake):

| Features | Test AUC | Test F1 |
|---|---|---|
| HSV only | 0.580 | 0.588 |
| FFT only | 0.637 | 0.607 |
| Wavelet only | 0.658 | 0.627 |
| FFT + Wavelet | **0.719** | **0.673** |
| HSV + FFT + Wavelet | 0.726 | 0.673 |

FFT + Wavelet features provided the best trade-off between complexity and performance, confirming that frequency-domain information is the most discriminative signal for deepfake detection — a finding that directly motivated the WaveletHybridNet architecture.

## Confusion Matrix

The confusion matrix below shows classification performance of WaveletHybridNet on the test set. The model achieves strong recall on FAKE images, with the primary failure mode being false negatives on high-quality synthetic portraits closely resembling real photography.

```
                  Predicted
                  REAL    FAKE
Actual  REAL  [  TN   |  FP  ]
        FAKE  [  FN   |  TP  ]
```

> The model performs best on **portrait / headshot images**.  
> AI-generated scenes and non-face content fall outside the training distribution.
